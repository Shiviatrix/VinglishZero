# Frozen Specifications

Place the immutable task specifications and prompt bundle here before any
generation begins. Each benchmark and level must identify feature requirements,
non-functional requirements, accepted dependencies, evaluator commands,
randomized seeds, timeouts, and security policy.

The previous comparison archive contains evaluators, but not the original
generation prompts or five-level task definitions. It is therefore insufficient
to populate this directory without reconstruction and review. Do not begin the
confirmatory study until the files here are reviewed and their hashes are added
to `../data/study-manifest.json`.
